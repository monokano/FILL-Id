FILL Idについて

何をするアプリか

FILL Idは、Adobe InDesignの機能にないペーストや表示の操作を、ホットキー（ショートカットキー）で実行するユーティリティアプリです。常駐して動作し、InDesignが最前面のときだけホットキーが有効になります。

主な機能は次の4つです。

  • クリーンペースト：クリップボードの文字を、貼り付け先の先頭の書式を保ったまま選択範囲へ流し込みます。InDesign標準の「書式なしでペースト」は、ルビが残る、貼り付け先の先頭の書式にならない、互換漢字が統合漢字に変わるといった困った仕様ですが、FILL Idのクリーンペーストはルビが残らず、先頭の書式になり、互換漢字も保護します。
  • 全体表示：ページ／見開き全体を表示します。InDesign標準の ⌘0 はメインキーボードの 0 でしか効きませんが、FILL Idではテンキーの 0 でも実行できます。
  • ズーム：拡大／縮小します。InDesign標準の ⌘＋ / ⌘− はメインキーボードの ＋ / − でしか効きませんが、FILL Idではテンキーの ＋ / − でも実行できます。
  • グリッドとガイドの表示切替：あらかじめ決めたグリッドやガイドの表示／非表示をまとめて切り替えます。

各機能の操作は使い方を、ON/OFFや細かい設定は設定をご覧ください。

動作の条件

FILL Idのホットキーは、InDesignが最前面のときだけ有効になります。InDesign以外のアプリを操作している間はホットキーが無効になり、ふだんのキー操作を妨げません。

メモ FILL IdがInDesignを操作するには、オートメーション（Apple Events）の許可が必要です。詳しくは権限とトラブルシューティングをご覧ください。

常駐とメニュー

FILL IdはメニューバーやDockに常駐します。メニューバーのアイコン、またはDockアイコンのメニューから、次の項目を開けます。

設定...
各機能のON/OFFや動作の設定。
ドキュメント表示設定...
グリッドとガイドの表示切替の設定。
ヘルプ
このヘルプを開きます。

メニューバーに表示するかDockに表示するかは、設定の「表示モード」で選べます。
